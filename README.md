# agrinho-2026
Esta página web foi projetada especificamente para o projeto Agrinho, funcionando como uma vitrine digital para apresentar os trabalhos desenvolvidos para o programa. Na abertura, o site destaca o tema central da sua pesquisa e o compromisso com a educação e a sustentabilidade no campo. Na seção intermediária, os blocos responsivos servem para expor as atividades práticas, desenhos, redações ou ações comunitárias realizadas pelos alunos. No encerramento, o rodapé disponibiliza os créditos da escola, dos professores orientadores e os canais de contato, oferecendo uma navegação clara e perfeitamente ajustada para celulares, tablets e computadores.
